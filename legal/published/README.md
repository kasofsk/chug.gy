# Published versions

Each file here is one published version of a policy, at
`<slug>/<version>.md`, where the version is the date it takes effect, such as
`terms/2026-09-15.md`. The binary embeds this directory and serves each file at
`https://chug.gy/<slug>/<version>` (as a page) and `.md` (as the bytes).

A file here is never changed once it is on `main`: its address and its digest
are what people agreed to. A new text is a new file under a new date.

The drafts are in the directory above and are not served.
